## Minimal source change in this branch

`initramfs/loader-init` now prints bounded LAN2 carrier (max five seconds), operstate, speed, duplex, interface address, RX/TX counters, link information, address and routes; distinguishes address setup failure and a Dropbear launch error from successful daemon launch. The earlier implementation printed `TERMINAL6_LOADER_ISOLATED_SSH_STARTED` after Dropbear failure; that false-positive marker is corrected.

This is **diagnostic/correctness remediation**, not a proven physical Ethernet fix. Even successful Dropbear launch is not proof of client SSH or carrier.
